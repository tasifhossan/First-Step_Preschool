# First Step School Education

A colourful, responsive HTML template for schools, kindergartens and education institutes. Built with Bootstrap, jQuery and Swiper.

## Pages

| Page | File | Description |
|---|---|---|
| Home | `index.html` | Banner slider, activities, courses, about, teachers, events, testimonials, gallery and contact |
| About | `about.html` | School story, mission / vision / values and teachers |
| Contact | `contact.html` | Contact details, social links and contact form |
| Login | `login.html` | Login form (email, password, remember me) |
| Sign Up | `signup.html` | Registration form with a password match check |

## Features

- Responsive layout that works on desktop, tablet and mobile
- Banner, event and testimonial sliders (Swiper)
- Scroll animations (WOW.js and Animate.css)
- Image gallery with popup (Magnific Popup)
- Sticky navbar with a mobile menu (SlickNav)
- Login and Sign Up buttons in the navbar
- Colour-coded design: orange `#ff5722`, blue `#1976d2`, green `#a4cf27`

## Tech Stack

- HTML5, CSS3, JavaScript
- Bootstrap
- jQuery 1.12.4
- Font Awesome and Flaticon icons
- Swiper, WOW.js, Magnific Popup, SlickNav, SmoothScroll
- Google Fonts: Bubblegum Sans and Roboto

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/tasifhossan/First-Step-School-Education-HTML-Template.git
   ```
2. Open `index.html` in your browser. No build step is needed.

## Customisation

- **Styles:** edit `css/custom.css`.
- **Scripts:** edit `js/function.js`.
- **Content and images:** replace the placeholder text in the HTML files and the files in `images/`.

## Notes

- The Login, Sign Up and Contact forms are front-end only. They post to `#` and need a backend or a form service to work.
- Most text is placeholder content.
